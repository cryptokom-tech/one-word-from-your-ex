## The word

> project

Not a partner — a project. Something to fix, renovate, and eventually
abandon halfway through. Lowercase, no punctuation: a text message with
nothing left to give. That is the whole joke and the whole sting — the ex
never saw a person, only a renovation that never finished.

## How it works

`main.py` (Python 3, standard library only) writes the word to `/output/entry.txt`. Run it with:

```sh
python3 -P -s main.py
```

It refuses to write unless the text is exactly one word and 1–30 characters.
